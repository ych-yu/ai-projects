# 🤖 AI周报生成器

基于**通义千问大模型**和 **Streamlit** 框架开发的智能办公助手。用户只需输入零散的工作内容，系统即可根据用户选择的岗位类型，自动生成符合该岗位风格的格式化周报。

## 🎯 项目背景

企业员工每周需撰写周报，不同岗位侧重点各异：
- **开发岗**：开发进度与Bug修复
- **产品岗**：需求分析与原型设计
- **销售岗**：客户拜访与签单金额

本项目通过大模型技术，将周报撰写时间从15-30分钟缩短至30秒以内，并保证岗位匹配度。

---

## ✨ 功能特性

- 🔄 **双模式交互**：快速模式（一次性生成）+ 对话模式（逐条汇总）
- 💼 **岗位智能匹配**：开发/产品/销售三套专用Prompt，自动切换输出风格
- 📜 **历史记录管理**：自动保存、逐条删除、一键清空，双模式独立存储
- 🛡️ **对话持久化**：切换模式或岗位时，对话内容不丢失
- ⏳ **加载动画**：API调用时显示等待动画
- 🚨 **异常处理**：空输入提醒、API失败提示，程序不崩溃

## 🚀 安装与使用

| 步骤 | 操作 |
|------|------|
| 克隆仓库 | `git clone https://github.com/ych-yu/ai-projects.git` |
| 安装依赖 | `pip install -r requirements.txt` |
| 配置Key | 在代码中填入你的阿里云百炼API Key |
| 本地运行 | `streamlit run weekly_report_final.py` |
| 云端部署 | 推送至GitHub → Streamlit Cloud关联仓库 → 一键部署 |

> ⚠️ 切勿将包含真实API Key的代码上传至公开仓库。

## 📝 使用说明

| 模式 | 操作流程 |
|------|----------|
| **快速模式** | 选择岗位 → 选择快速模式 → 输入全部工作内容 → 点击生成 → 查看周报 |
| **对话模式** | 选择岗位 → 选择对话模式 → 逐条输入工作内容 → 输入"生成周报" → AI汇总生成 |
| **历史管理** | 查看历史记录 → 逐条删除或一键清空 |

## 🏗️ 项目架构
用户界面（Streamlit网页）
├── 侧边栏：岗位选择 / 模式切换 / 清空历史

├── API调用（qwen-plus）
└── 状态管理（st.session_state）

部署层
└── Streamlit Cloud
